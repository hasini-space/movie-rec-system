# Movie Recommendation System

A Python-based movie recommendation system that helps users discover new movies based on their preferences and viewing history.

## 🎬 Live Demo

Try the live application here: [Movie Recommendation System Demo](https://k8kv2shmtsmvgr5e6zbbqx.streamlit.app/)

## Features

- **Personalized Recommendations**: Generates tailored movie suggestions based on user preferences
- **Collaborative Filtering**: Leverages user behavior patterns to identify similar viewers
- **Content-Based Filtering**: Recommends movies based on genres, cast, and other attributes
- **Rating System**: Allows users to rate and review movies
- **Movie Database**: Comprehensive database of movies with metadata

## Tech Stack

- **Python** (92.2%) - Core application logic
- **Perl** (4.1%) - Utility scripts
- **Shell** (3.7%) - System automation and deployment

## Installation

1. Clone the repository:
```bash
git clone https://github.com/hasini-space/movie-rec-system.git
cd movie-rec-system
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
